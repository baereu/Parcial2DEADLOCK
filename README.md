## ¿De qué trata?

Es una página para guardar y administrar personajes de DEADLOCK. Está hecha con HTML, CSS y JavaScript. Los cambios se guardan en el navegador con "localStorage", por lo que se conservan al recargar la página.
Tiene incluidos seis personajes iniciales: Mina, Celeste, Enfermera Hallow, Solomon, Vindicta y Seven. 

## ¿Qué se puede hacer?

- Ver los personajes en fichas y consultar sus detalles.
- Agregar, editar y eliminar personajes.
- Buscar por nombre o rol.
- Agregar imágenes mediante un enlace directo.
- Usar la página en computadora o celular jeje

Se revisa que nombre y rol estén completos y evita nombres repetidos. Si una imagen no carga, aparecen las iniciales del nombre.

## Cómo usarla

1. Abrir el enlace de GitHub Pages. O descargar el proyecto completo y abrir index.html
2. Pulsar "Ver detalle" para consultar los detalles de un personaje.
3. Puedes crear uno, pulsando "Agregar personaje", solo completa el formulario y guardalo.
4. Para modificarlo, entra en sus detalle y pulsa "Editar".
5. Para borrarlo, presiona "Eliminar" y confirma.
6. Usa el buscador para encontrar personajes y "Limpiar búsqueda" para ver todos.

Cada navegador guarda su propia colección. Asi que los cambios no se comparten con otras personas. Y las imágenes externas necesitan conexión a internet.

## Archivos del proyecto

- index.html: estructura de la página.
- css/style.css: colores y diseño.
- js/deadlockP.js: funciones y personajes iniciales.
- img/: logo del videojuego.
- personajes-ejemplo.json: datos de seis personajes para la entrega, la página no lee este archivo.
- BITACORA.md: explicación de las decisiones del proyecto.
